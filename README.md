# Blue Sky Social Media

## About
Blue Sky is a simple social media website created as a Full Stack Development learning project for the CodeAlpha internship.

## Features
- Create and publish posts
- Add an image URL to a post
- Like, Love, Haha, Wow, Sad, and Angry reactions
- Add comments to posts
- Search posts
- Responsive website design
- Basic Express.js server and API routes

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB with Mongoose (database setup)

## Project Files
- `index.html` - Website structure
- `style.css` - Website design
- `script.js` - Frontend functionality
- `server.js` - Backend server
- `package.json` - Project configuration
- `database.js` - Database connection setup
- `models.js` - Post database model
- `routes.js` - Post API routes

## How to Run
1. Install Node.js.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Configure the required database connection if using MongoDB.
5. Run `npm start`.
6. Open `http://localhost:3000` in your browser.

## Purpose
This project is for educational and internship practice.
